# UnoPlatformAdMob

AdMob wrapper control for Uno Platform using WebView2 and the AdMob JavaScript SDK.

## Quick Start

```xaml
<Page xmlns:admob="using:UnoPlatformAdMob">
    <admob:AdMobView 
        AdUnitId="ca-app-pub-XXXXXXXXXXXXXXXX/YYYYYYYYYY"
        AdFormat="Banner"
        Height="250"/>
</Page>
```

## Features

- Cross-platform AdMob ad display
- Support for Banner, In-Article, and In-Feed ad formats
- Simple integration with WebView2
